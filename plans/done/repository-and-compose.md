## Что мы делаем?

Подготавливаем понятный репозиторий rdsh с README.md и примерами быстрого запуска ровно двух сервисов: `gateway` и `dsh`. Пользователь монтирует выделенную папку как `/home/dsh`, задаёт публичный адрес, постоянные учётные данные и версию DSH. Поддерживаются автоматический HTTPS и работа по HTTP за существующим reverse proxy без конфликта за порты 80/443.

План зависит от интерфейсов [шлюза](auth-gateway.md) и [контейнера DSH](dsh-runtime.md). Каркас репозитория готовится первым, а рабочие примеры и финальный README — после интеграции контейнеров. На момент составления планов каталог проекта пуст и Git ещё не инициализирован. Все пути ниже — предлагаемая структура. Резервное копирование, восстановление бэкапов и многопользовательская платформа вне рамок проекта.
